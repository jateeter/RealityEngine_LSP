# RealityEngine_LSP Tests Guidance

This directory contains Lisp unit and e2e tests.

- Run `make test` for local changes.
- Use e2e tests for RE/PE endpoint, OpenClaw, HealthKit/Spezi, or corpus behavior.
- Report parity failures separately from service availability.

## Standing rules

The standing rules are in
`../../RealityEngine_CI/docs/ENGINEERING_CONTRACT.md`, which is
authoritative. They are not listed or summarised here, so this file never
falls behind the contract. Read it before changing anything here.
